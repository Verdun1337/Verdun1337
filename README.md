## Focus areas

- **Backend engineering (Java/Spring, .NET):** building stable APIs, clear domain models, and maintainable architecture.
- **Security & identity:** OAuth2/JWT flows, Spring Security, and pragmatic authorization patterns.
- **Event-driven & CQRS mindset:** integration events, read-models, idempotency, and replayable state.
- **Practical DevOps:** Docker-first workflows, CI/CD basics, and deployment-oriented project structure.
- **Applied AI/ML (learning-focused):** fuzzy logic + classic models with clean project organization and clear disclaimers.

## How I work

- I optimize for **clarity and durability**: readable code, explicit trade-offs, predictable behavior.
- I like **systems that can be reasoned about**: well-defined domain boundaries, contracts, and invariants.
- I care about **operational concerns early**: validation, error handling, idempotency, and replay/rebuild paths.
- I prefer **boring solutions that scale** over clever solutions that break.
